# Sales documents

Templates for outreach to group home agencies. Open in Microsoft Word:

1. **File → Open** and select the `.md` file, or  
2. Copy the file contents into a new Word document, or  
3. Use **Pandoc** (optional): `pandoc PILOT-PROPOSAL.md -o PILOT-PROPOSAL.docx`

| File | Purpose |
|------|---------|
| `PILOT-PROPOSAL.md` | 90-day pilot proposal with signature block |
| `SALES-COMPARISON.md` | Feature comparison and objection handling (internal + sales) |

Replace all `[bracketed]` placeholders before sending.
